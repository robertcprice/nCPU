# Demos

## Quick Start
See the guided demo map: `python -m ncpu demos --verbose`

## Structure
- `showcase/`: Lightweight, cross-platform interactive experiences (discovery, text machine, etc.).
- `gpu/`: Systems demos (BusyBox, Alpine, self-hosting, determinism toolkit — the hero GPU computer path).
- `neural/`: Research-depth neural demos (full neural, coprocessor, meta-comparisons).
- `practicality/`: Practicality and scale reports (npcot coding/scale, synth).
- `generated/`: Auto-generated outputs from demos.

The hero path is under `gpu/`. Research extensions live in `neural/` and `coprocessor/`.

Add new demos to the most specific subdir. Keep top-level clean.
