# examples/

Minimal, runnable entry-point demos showing each layer of the neural CPU in
isolation:

- `demo_neural_cpu.py` — drive the neural ALU / CPU path.
- `demo_model_cpu.py` — the model-backed CPU.
- `demo_tensor_cpu.py` — the tensor execution path.

Run from the repo root, e.g. `python examples/demo_neural_cpu.py`. For the larger
showcase walkthroughs see `demos/`.
