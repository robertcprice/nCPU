# Tools & Utilities

Internal tools, scripts, and helpers for development, distillation, benchmarking, etc.

## Structure
- `internal/`: Core one-off and development scripts (.py, .sh).
- `distillation/`: Distillation-related tools and configs.
- `benchmarks/`: Benchmark helpers and related.

Large or dated outputs go to artifacts/archive/.

These support the hero thesis (GPU computer + JEPA Neural OS direction) but are not the primary user-facing surface.
