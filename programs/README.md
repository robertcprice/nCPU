# programs/

The program corpus used by the synthesis benchmarks — reference programs and
I/O specifications the differentiable compiler (Mog) and nSynth synthesize and
verify against, grouped by category:

- `arithmetic/`, `bitwise/`, `algorithms/`, `memory/`, `hardware/` — problem
  families spanning the synthesis benchmark suite.
- `test/` — fixtures for the synthesis harness.

These define the 315 (Mog) / 95 (nSynth) benchmark problems whose coverage is
reported in `artifacts/`.
